# Mobsters Font

Place the following files here (download from https://www.dafont.com/mobsters.font or the Sharkshock foundry):

- Mobsters.woff2  (preferred)
- Mobsters.woff
- Mobsters.ttf

Once placed, the @font-face in globals.css will pick them up automatically.
The site falls back to a serif font until the file is present.
